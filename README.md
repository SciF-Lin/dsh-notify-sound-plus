# dsh-notify-sound-plus

给 DeepSeek Harness 加一套**提示提醒**：任务做完了、需要你回答、需要你授权、出错了，
各有提示音；也可以弹**系统通知**，让切到别的窗口时照样能收到。

网页版和桌面端都能用。

## 能做什么

- **四类事件，四种声音**，一耳朵就能听出是哪种情况。
- **系统通知**：需要你回答 / 需要你授权 / 任务完成时，弹出系统通知中心的提醒，
  切到别的应用也不会错过。
- **在设置里直接选**：哪个事件要提示、用哪个声音，都能单独调，选完自动播给你听。
- **换成你自己的声音**：可以上传 mp3 / wav 等音频文件当提示音。
- **智能判断**：如果你装了鲸鱼余额挂件，它已经在提示的事件就不重复提示，避免两声叠在一起。
- **一键静音**：对话输入框左下角有个小喇叭，点一下就临时关掉声音，再点恢复。
- 默认不吵你：子任务跑完不提示，你自己按的停止不提示，刷新页面也不会把旧提醒重播一遍。

## 四种提示

| 什么时候 | 默认声音 |
|---|---|
| 任务完成 | 下行双音，清脆的"叮——咚" |
| 需要你回答 | 上行三音，像在追问 |
| 需要你授权 | 低音三连，有点敲门的感觉 |
| 出错 | 低沉下坠，一听就知道不对 |

另外内置「叮咚 / 铃音 / 轻柔 / 警示」四种可换。

## 怎么用

### 1. 安装

```powershell
# 网页版
dsh plugin --profile web add dsh-notify-sound-plus

# 桌面端
dsh plugin --profile desktop add dsh-notify-sound-plus
```

装完**重启 DSH** 就生效。

### 2. 通用设置里的那一行

打开「设置 → 通用」，会看到「声音提醒」：

- **模式下拉框**：
  - `开启声音提示` —— 所有事件都提示
  - `关闭声音提示` —— 都不提示
  - `智能判断` —— 鲸鱼挂件已经提示的不重复提示
- **播放图标**：听一下「任务完成」的声音。
- **齿轮图标**：打开完整设置窗口。

### 3. 完整设置窗口（点齿轮）

弹出的窗口里分成三组：

- **声音提示**：四个事件各配一个开关 + 声音下拉 + 播放按钮；
  音量滑杆；「应用在前台运行时不提示」。
- **系统通知**：一个总开关（打开时会申请系统通知权限）+ 四个事件各自的开关。
  系统通知与声音是**两条独立通道**——临时静音只静声音，不影响系统通知。
- **自定义音频**：上传自己的音频（mp3 / wav / ogg / m4a，单个 ≤ 2MB）。

### 4. 临时静音

对话输入框左下角的小喇叭：

- 点一下 → 已关闭提示音
- 再点一下 → 已开启提示音

这个开关**重启就恢复**，不用担心忘了打开。

## 常见问题

**完全没声音？**

1. 先看设置里模式是不是 `关闭声音提示`，或者喇叭是不是静音了。
2. 浏览器有个规定：页面在你**第一次点击或按键之前**不允许出声。
   随便点一下页面就行，插件会自动补上刚才那一声。

**和鲸鱼挂件的提示音重叠？**

把模式设成「智能判断」即可，它会自动避让。

**声音能换成自己的吗？**

可以。设置里「上传音频」选文件，支持 mp3 / wav / ogg / m4a，单个 2MB 以内。

**为什么装不上 / 提示找不到包？**

npm 上 `dsh-notify-sound` 这个名字已经被别人占了，所以本插件的包名是
`dsh-notify-sound-plus`。用上面的命令即可。
